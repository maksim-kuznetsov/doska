# admin-outbox Specification

## Purpose

Даёт администратору временный способ видеть письма, сохраняемые файловым отправителем (подтверждение email, сброс пароля, решения модерации), когда реальная отправка по SMTP ещё не настроена.

## Requirements

### Requirement: Список писем файлового ящика

Система SHALL предоставлять администратору список писем, сохранённых в файловом ящике (`Email:OutboxPath`), с датой, размером и именем файла. Доступ SHALL требовать роль `Admin`.

#### Scenario: Просмотр списка
- **WHEN** администратор открывает раздел писем
- **THEN** он видит письма файлового ящика, упорядоченные от новых к старым

#### Scenario: Пустой ящик
- **WHEN** в файловом ящике нет писем
- **THEN** список пуст, а страница показывает, что писем нет

#### Scenario: Доступ только администратору
- **WHEN** список писем запрашивает неавторизованный пользователь или не администратор
- **THEN** сервер отвечает отказом и не раскрывает содержимое ящика

### Requirement: Просмотр содержимого письма

Система SHALL позволять администратору открыть выбранное письмо и увидеть его текст (получатель, тему, дату и тело). Изменение или удаление писем через страницу MUST NOT выполняться.

#### Scenario: Чтение письма
- **WHEN** администратор выбирает письмо в списке
- **THEN** он видит его получателя, тему и тело, включая ссылку подтверждения или причину решения

#### Scenario: Только чтение
- **WHEN** администратор работает со страницей писем
- **THEN** доступны только просмотр списка и чтение, без изменения и удаления файлов

### Requirement: Защита каталога писем

Система SHALL читать только файлы из каталога `Email:OutboxPath` и MUST NOT отдавать файлы за его пределами.

#### Scenario: Обход каталога
- **WHEN** запрос содержимого пытается выйти за пределы каталога писем через имя файла
- **THEN** сервер отклоняет запрос и не читает посторонний файл

#### Scenario: Отсутствующий файл
- **WHEN** запрошено содержимое несуществующего файла
- **THEN** сервер отвечает «не найдено»
