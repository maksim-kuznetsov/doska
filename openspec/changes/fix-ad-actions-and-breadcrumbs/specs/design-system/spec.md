# Spec Delta

## MODIFIED Requirements

### Requirement: Навигационные элементы
Система SHALL предоставлять хлебные крошки, пагинацию и состояние пустой выдачи в едином оформлении. Хлебные крошки SHALL содержать только шаги, ведущие на другую страницу, и MUST NOT показывать шаги без адреса перехода.

#### Scenario: Хлебные крошки
- **WHEN** пользователь находится на вложенной странице
- **THEN** отображается цепочка хлебных крошек

#### Scenario: Шаг без ссылки
- **WHEN** в наборе шагов крошек есть элемент без адреса перехода, например название текущей страницы или раздела
- **THEN** такой шаг не выводится

#### Scenario: Кликабельный шаг
- **WHEN** в наборе шагов крошек есть элемент с адресом перехода
- **THEN** он выводится ссылкой на соответствующую страницу

#### Scenario: Пустая выдача
- **WHEN** по заданным условиям нет результатов
- **THEN** показывается пустое состояние вместо пустого списка

## ADDED Requirements

### Requirement: Модальный диалог действия
Система SHALL предоставлять переиспользуемый модальный диалог для действий, требующих ввода или подтверждения: с заголовком, полями ввода, действиями подтверждения и отмены и закрытием по клавише Esc и клику вне диалога.

#### Scenario: Открытие диалога
- **WHEN** пользователь запускает действие, требующее ввода или подтверждения
- **THEN** открывается модальный диалог с заголовком, полями и действиями подтверждения и отмены

#### Scenario: Подтверждение действия
- **WHEN** пользователь заполняет поля и подтверждает действие
- **THEN** диалог передаёт введённые данные вызывающему и закрывается

#### Scenario: Отмена действия
- **WHEN** пользователь отменяет действие, закрывает диалог по Esc или клику вне него
- **THEN** диалог закрывается без выполнения действия

#### Scenario: Обязательное поле
- **WHEN** пользователь подтверждает действие, не заполнив обязательное поле
- **THEN** система не выполняет действие и указывает на незаполненное поле
