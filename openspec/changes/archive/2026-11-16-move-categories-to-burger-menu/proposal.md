# Proposal

## Why

Бар категорий в шапке занимает отдельную полосу под поиском и отодвигает ленту объявлений вниз на всех представлениях. Хочется убрать эту полосу и спрятать дерево категорий в компактное выпадающее меню, которое вызывается по требованию из шапки.

## What Changes

- Убрать постоянную полосу категорий (`.ds-category-bar`) из шапки в `web/src/layouts/AppLayout.vue` (`web/src/components/AppHeader.vue`).
- Показывать дерево категорий в выпадающем меню, которое раскрывается кнопкой-бургером рядом с брендом в шапке (доступно на всех представлениях).
- Убрать выпадающее меню у заголовка главной: заголовок ленты в `web/src/views/FeedView.vue` остаётся обычным `<h1>` без триггера.
- Меню закрывается по повторному нажатию, по клику вне меню и по клавише Escape; кнопка отражает состояние через `aria-expanded`.
- Добавить в дизайн-систему переиспользуемый компонент «бургер + выпадающее меню», оформить его токенами и показать в странице-гайде.

### Modified Capabilities
- `design-system`: базовый макет больше не содержит полосу категорий в шапке; библиотека компонентов дополняется бургер-кнопкой и выпадающим меню; страница-гайд показывает новый компонент.
- `categories`: отображение дерева активных разделов раскрывается через выпадающее меню, вызываемое бургер-кнопкой в шапке, вместо постоянной полосы.

## Impact

- Компоненты: `web/src/components/AppHeader.vue`, новый общий компонент меню `web/src/components/CategoryBurger.vue`, `web/src/views/DesignSystemGuide.vue`.
- Стили: `web/src/assets/css/components.css` (бургер и выпадающее меню), `web/src/assets/css/layout.css` (группа бренда, удаление правил `.ds-category-*`).
- Поведение: новый общий composable `web/src/composables/useDropdownMenu.ts` (переключение, наведение, клик вне, Escape), подключается в `web/src/components/AppHeader.vue`.
- Тесты: `web/src/components/__tests__/AppHeader.spec.ts` (тест «неактивная категория исчезает из дерева» — имена категорий по-прежнему должны присутствовать в разметке главной), новые проверки разметки бургер-меню.
- Пользовательский интерфейс: категории исчезают с постоянной полосы в шапке; доступ к ним — через бургер в шапке.
