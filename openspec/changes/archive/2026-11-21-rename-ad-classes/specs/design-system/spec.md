# Spec Delta

## ADDED Requirements

### Requirement: Устойчивость имён классов к блокировщикам рекламы

Система SHALL давать блокам объявлений имена классов, которые не совпадают с токенами, скрываемыми универсальными косметическими фильтрами блокировщиков рекламы (общие правила без привязки к домену). Классы сетки ленты, списков, карточки, строки и страницы объявления MUST NOT начинаться с токена `ad-`.

#### Scenario: Лента при включённом блокировщике

- **WHEN** пользователь с включённым блокировщиком рекламы открывает главную страницу
- **THEN** сетка и карточки объявлений видны, а не скрыты

#### Scenario: Списки и страница объявления при включённом блокировщике

- **WHEN** пользователь с включённым блокировщиком открывает «Мои объявления» или страницу объявления
- **THEN** строки списка и блоки объявления видны, а не скрыты

#### Scenario: Имя класса не совпадает с общим правилом

- **WHEN** проверяется любой класс оформления блоков объявлений
- **THEN** он не совпадает с универсальными косметическими правилами блокировщиков (`ad-card`, `ad-grid`, `ad-row`, `ad-detail` и подобными)
