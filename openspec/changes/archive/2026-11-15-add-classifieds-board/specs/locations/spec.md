# Spec Delta

## Purpose

Определяет справочник городов, которым управляет администратор, и выбор города в объявлении.

## ADDED Requirements

### Requirement: Справочник городов

Система SHALL хранить список городов, которым управляет только администратор, и SHALL использовать этот список при подаче и фильтрации объявлений.

#### Scenario: Добавление города

- **WHEN** администратор добавляет город в справочник
- **THEN** город становится доступен для выбора при подаче объявления и для фильтра

#### Scenario: Переименование города

- **WHEN** администратор переименовывает город
- **THEN** новое название отображается в существующих объявлениях и фильтрах

#### Scenario: Модератор не управляет справочником

- **WHEN** модератор пытается добавить или изменить город
- **THEN** система запрещает действие

#### Scenario: Деактивация города

- **WHEN** администратор деактивирует город
- **THEN** город исчезает из выбора при подаче, а существующие объявления с ним остаются доступными

### Requirement: Обязательный выбор города

Система SHALL требовать выбора города из активного списка при подаче объявления и SHALL отклонять произвольный текст вместо города.

#### Scenario: Выбор из списка

- **WHEN** пользователь выбирает активный город при подаче объявления
- **THEN** объявление сохраняется с привязкой к этому городу

#### Scenario: Произвольный текст

- **WHEN** пользователь пытается указать город, которого нет в активном справочнике
- **THEN** система не принимает значение и просит выбрать город из списка

#### Scenario: Фильтр по городу

- **WHEN** посетитель выбирает город в фильтре
- **THEN** система показывает только объявления этого города
