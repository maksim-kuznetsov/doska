# Proposal

## Why

Нужна публичная доска объявлений с категориями и разграничением ролей. Сейчас в проекте нет ни кода, ни спецификаций: площадка создаётся с нуля. Без модерации и антиспам-механик публичная лента быстро заполняется мусором, поэтому роли, проверка объявлений и лимиты закладываются с первой версии.

## What Changes

- Публичная доска: пользователи размещают объявления в подразделах дерева категорий; объявления видны всем без регистрации.
- Роли: пользователь, модератор, администратор. Одна роль на пользователя.
- Гибридная модерация: объявления новых пользователей попадают в очередь проверки, доверенные публикуются сразу.
- Доверие: автоматически после 3 одобренных объявлений, плюс ручное повышение и понижение модератором или администратором.
- Лимит: не более 5 объявлений в сутки для непроверенных, без лимита для доверенных.
- Жизненный цикл: на проверке, активно, продано, архив через 7 дней, отклонено и скрыто с причиной. Продление доступно автору. Черновиков нет.
- Жалобы: одна жалоба на пользователя на объявление, нельзя жаловаться на своё, автоскрытия по количеству жалоб нет.
- Регистрация по email и паролю с подтверждением адреса; сброс пароля по ссылке. OAuth откладывается.
- Поиск и фильтры: текст, категория, город, диапазон цены, сортировка, пагинация.
- Справочники: дерево категорий (2 уровня) и список городов, управляемые администратором.
- Уведомления: статусы в «Моих объявлениях» и email при отклонении, скрытии и скором истечении срока.

## Capabilities

### New Capabilities

- `user-accounts`: регистрация с подтверждением email, вход, сброс пароля, роли и их права, блокировка пользователей.
- `classified-ads`: подача и редактирование объявлений, общий набор полей и фото, статусы и жизненный цикл, срок 7 дней и продление, суточный лимит подачи.
- `categories`: дерево категорий глубиной 2 уровня, управление администратором, привязка объявления к подразделу.
- `locations`: справочник городов, управляемый администратором, выбор города в объявлении.
- `ad-search`: поиск по тексту и фильтры по категории, городу и цене, сортировка и пагинация.
- `ad-moderation`: очередь проверки, одобрение, отклонение и скрытие с причиной, жалобы, автоматическое и ручное управление уровнем доверия.
- `notifications`: статусы объявлений в интерфейсе и email-уведомления о значимых событиях.

### Modified Capabilities

Нет: проект пустой, существующих спецификаций не затрагиваем.

## Impact

- Новый проект: SPA на Vue 3 и Web API на ASP.NET Core, база PostgreSQL, разворачивается в Docker на одном VPS.
- Хранилище фото: каталог `media/` на локальном томе, отдача через nginx, сжатие при загрузке через ImageSharp, внешний бэкап; доступ через абстракцию `IFileStorage` для последующего переезда на S3-совместимое хранилище.
- Почта: Resend.
- Фоновые задачи: `BackgroundService` в `src/Doska.Api` для автоархива и писем об истечении срока.
- Вне scope первой версии: OAuth, чат между пользователями, избранное, геопоиск, автоскрытие по жалобам, черновики, мобильное приложение, MinIO.
