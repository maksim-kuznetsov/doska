# Spec Delta

## MODIFIED Requirements

### Requirement: Подача объявления
Система SHALL принимать объявление с заголовком, описанием, ценой в рублях, городом, подразделом категории, контактами и фотографиями, и SHALL требовать заполнения всех обязательных полей. Форма подачи нового объявления SHALL предзаполнять поле контактов отображаемым именем и контактами профиля автора в формате «имя контакты», оставляя значение редактируемым.

#### Scenario: Успешная подача
- **WHEN** подтверждённый пользователь заполняет обязательные поля и прикладывает от 1 до 5 фотографий
- **THEN** система сохраняет объявление и присваивает ему статус по правилам модерации

#### Scenario: Незаполненное обязательное поле
- **WHEN** пользователь отправляет форму без заголовка, описания, цены, города, подраздела или контактов
- **THEN** система не сохраняет объявление и указывает незаполненные поля

#### Scenario: Некорректная цена
- **WHEN** пользователь указывает отрицательную, нечисловую или превышающую допустимый максимум цену
- **THEN** система отклоняет значение и просит ввести неотрицательное число в допустимых границах

#### Scenario: Контакты предзаполнены из профиля
- **WHEN** подтверждённый пользователь с сохранёнными отображаемым именем и контактами открывает форму подачи нового объявления
- **THEN** поле «Контакты» содержит отображаемое имя и контакты профиля, разделённые пробелом, и доступно для изменения перед отправкой

#### Scenario: В профиле только контакты без имени
- **WHEN** пользователь открывает форму подачи нового объявления, а в профиле заполнены контакты, но не заполнено отображаемое имя
- **THEN** поле «Контакты» содержит только контакты профиля без лишнего пробела

#### Scenario: В профиле нет ни имени, ни контактов
- **WHEN** пользователь открывает форму подачи нового объявления, а отображаемое имя и контакты в профиле не заполнены
- **THEN** поле «Контакты» пустое и заполняется вручную
