# Spec Delta

## REMOVED Requirements

### Requirement: Блок разделов на главной
**Reason**: Блок разделов и подразделов плитками перекрывал основную форму на главной странице и дублировал навигацию по разделам, которая уже есть в постоянной полосе шапки.

**Migration**: Разделы на главной доступны через постоянную горизонтальную полосу разделов в шапке (`CategoryStrip`) и меню категорий через бургер, а фильтр по разделу — в панели фильтров. Отдельного действия от пользователя не требуется.
