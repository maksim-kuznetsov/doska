# Spec Delta

## MODIFIED Requirements

### Requirement: Единый источник оформления страниц
Система SHALL собирать все представления интерфейса из компонентов дизайн-системы; страницы MUST NOT вводить классы оформления вне дизайн-системы.

#### Scenario: Представление использует компоненты системы
- **WHEN** открывается любая страница сайта
- **THEN** её разметка собрана из компонентов дизайн-системы и не вводит классы оформления вне дизайн-системы

#### Scenario: Подключаются только стили дизайн-системы
- **WHEN** страница загружает стили
- **THEN** подключаются только токены (`frontend/src/assets/css/tokens.css`), базовые стили, компоненты и раскладка

### Requirement: Страница-гайд дизайн-системы
Система SHALL предоставлять страницу-гайд (`frontend/src/views/DesignSystemGuide.vue`) на маршруте `/design-system`, показывающую токены и все компоненты с примерами разметки, доступную только в окружении `Development`.

#### Scenario: Просмотр гайда
- **WHEN** разработчик открывает адрес гайда в окружении `Development`
- **THEN** он видит токены и примеры всех компонентов

#### Scenario: Примеры новых компонентов
- **WHEN** разработчик открывает гайд после перевода представлений на компоненты дизайн-системы
- **THEN** на странице есть примеры фильтров с диапазоном цены и строкой результатов, галереи, строк списка, карточек модерации, подсказок к паролю, бургер-меню, ссылки-действия с иконкой, а также секций формы, сетки коротких полей, зоны загрузки фотографий и счётчика символов

#### Scenario: Гайд в production
- **WHEN** окружение — `Production`
- **THEN** страница-гайд недоступна
