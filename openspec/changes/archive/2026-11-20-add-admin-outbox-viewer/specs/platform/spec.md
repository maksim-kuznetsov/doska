# Spec Delta

## MODIFIED Requirements

### Requirement: Почта в production

В `Production` система SHALL отправлять письма через настроенный SMTP-провайдер либо, как временный вариант, сохранять их в файловый ящик (`Email:Mode=File`) с абсолютным `Email:OutboxPath`; SMTP остаётся штатным режимом. Ссылки подтверждения email и сброса пароля SHALL быть абсолютными и вести на публичный адрес сайта. Без заданного публичного адреса приложение в `Production` MUST NOT запускаться.

#### Scenario: Абсолютная ссылка в письме

- **WHEN** пользователь регистрируется или запрашивает сброс пароля на боевом стенде
- **THEN** письмо содержит ссылку вида `https://<домен>/confirm-email?token=...`, открывающую нужную страницу сайта

#### Scenario: Отсутствие публичного адреса

- **WHEN** приложение запускается в `Production` без настроенного публичного адреса сайта
- **THEN** запуск завершается ошибкой с указанием отсутствующей настройки

#### Scenario: Отправка через SMTP

- **WHEN** заданы хост, учётные данные и адрес отправителя SMTP
- **THEN** письма уходят через выбранного провайдера, а не сохраняются в журнал

#### Scenario: Временный файловый режим в Production

- **WHEN** приложение запускается в `Production` с `Email:Mode=File` и абсолютным `Email:OutboxPath`
- **THEN** запуск проходит, а письма сохраняются в указанный каталог вместо отправки пользователям

#### Scenario: Файловый режим без каталога

- **WHEN** в `Production` выбран `Email:Mode=File` без абсолютного `Email:OutboxPath`
- **THEN** запуск завершается ошибкой с указанием отсутствующей настройки
