# Proposal

## Why

На публичной странице объявления нет действий: автор не может перейти к редактированию, а посетитель — подать жалобу, хотя API и правила обеих возможностей уже есть. Одновременно в хлебных крошках вернулись шаги без ссылки: их исправление осталось на невлитой ветке `remove-non-clickable-breadcrumb-steps` (коммит `a615672`) и в `master` не попало.

## What Changes

- На странице объявления появляется панель действий: автору — «Редактировать», остальным — «Пожаловаться».
- Жалоба подаётся через диалог с обязательным полем причины: новый переиспользуемый компонент диалога дизайн-системы (по образцу `PhotoViewer` на `<dialog>`).
- Ответ детальной страницы объявления сообщает клиенту, принадлежит ли объявление текущему пользователю, чтобы показать авторское действие.
- Восстанавливается потерянное правило хлебных крошек: крошки содержат только шаги со ссылкой, элементов без перехода нет.
- Устаревшая ветка `remove-non-clickable-breadcrumb-steps` считается мёртвой: фикс переделывается этим изменением, ветку удаляем.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `design-system`: требование «Навигационные элементы» — хлебные крошки содержат только кликабельные шаги; добавляется требование к переиспользуемому модальному диалогу с полем и подтверждением.
- `classified-ads`: требование «Публичный просмотр объявления» — автор видит на странице объявления действие редактирования, клиент получает признак авторства.
- `ad-moderation`: требование «Жалобы на объявления» — жалоба подаётся со страницы объявления через диалог с причиной; действие показывается только для чужого активного объявления.

## Impact

- Интерфейс: `frontend/src/views/AdDetailView.vue`, новый компонент диалога и компонент `Breadcrumbs.vue`, представления админ-разделов и `AdEditView`, их тесты, `frontend/src/styles` при необходимости.
- Бэкенд: ответ детальной страницы объявления (`AdSummary`/`AdResponse`) получает признак авторства; остальные правила не меняются. Соответствие `openspec/specs/platform/spec.md` сохраняется: бизнес-правила остаются на сервере, клиент только скрывает недоступные действия.
- Git: восстановление правила крошек переделывается вместо влития ветки `remove-non-clickable-breadcrumb-steps`.

## Вне рамок

- Изменение API жалоб и редактирования: эндпоинты, валидация и права уже есть.
- Список причин и модерация жалоб (очередь, решения) — не затрагиваются.
- Прочие действия автора (продано, продление, удаление) на странице объявления.
- Изменение внешнего вида и раскладки страницы объявления помимо панели действий.
