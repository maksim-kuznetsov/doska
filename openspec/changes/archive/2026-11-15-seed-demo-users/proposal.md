# Proposal

## Why

Чтобы проверять роли и права вручную, сейчас приходится каждый раз создавать пользователей через административные эндпоинты `/api/admin/...` и вручную выставлять им роль. Это медленно и легко ошибиться: забыть подтвердить email, выдать не ту роль, перепутать модератора с администратором. Стартовый набор демо-аккаунтов по одной штуке на каждую роль делает локальную проверку предсказуемой и воспроизводимой.

## What Changes

- Seed-сервис в `src/Doska.Infrastructure`, запускаемый командой `dotnet run --project src/Doska.Api -- seed`, дополнительно создаёт трёх демо-пользователей: обычный пользователь, модератор, администратор.
- Все трое с подтверждённым email и общим паролем `123789`; администратор получает роль `UserRole.Admin` для доступа к административным эндпоинтам `/api/admin/...`.
- Seed-сервис остаётся идемпотентным: уже существующие адреса не перезаписываются, пароль и роль существующего пользователя не меняются.
- После заполнения seed-сервис печатает предупреждение, что демо-аккаунты нужно удалить перед production.
- README получает раздел с таблицей кредов и командой удаления демо-аккаунтов; `deploy/DEPLOY.md` — обязательный шаг удаления после запуска seed-сервиса.
- **BREAKING** для production-процедуры: запуск seed-сервиса на боевом сервере теперь создаёт известные логины с паролем из README. Инструкция деплоя требует удалить их сразу после заполнения справочников.

## Capabilities

### New Capabilities

Нет. Демо-аккаунты — инструмент разработчика, а не поведение площадки для посетителей.

### Modified Capabilities

Нет. Требования к регистрации, ролям, правам и модерации не меняются: наполнение базы не является частью пользовательских сценариев.

Change объявлен с `skip_specs: true`.

## Impact

- `src/Doska.Infrastructure` (seed-сервис): создание демо-пользователей и предупреждение в выводе.
- `tests/Doska.Tests` (xUnit): проверки набора, ролей, подтверждения email, пароля и идемпотентности.
- `README.md`: раздел «Демо-аккаунты» с кредами и удалением.
- `deploy/DEPLOY.md`: шаг удаления демо-аккаунтов после заполнения справочников.
- Существующие данные не затрагиваются: пользователи с теми же адресами остаются как есть.
