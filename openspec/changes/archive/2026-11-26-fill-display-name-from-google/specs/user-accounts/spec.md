# Spec Delta

## ADDED Requirements

### Requirement: Заполнение отображаемого имени из Google
Система SHALL сохранять отображаемое имя пользователя из подтверждённого имени Google, когда оно ещё не задано: при создании аккаунта через Google, при автоматической привязке к существующему аккаунту и при явной привязке из профиля. Уже заданное отображаемое имя SHALL оставаться неизменным.

#### Scenario: Новый аккаунт через Google
- **WHEN** пользователь впервые входит через Google с подтверждённым email и именем, а аккаунта ещё нет
- **THEN** система создаёт аккаунт и сохраняет имя Google как отображаемое имя профиля

#### Scenario: Автопривязка к существующему аккаунту без имени
- **WHEN** Google-идентичность автоматически привязывается к существующему аккаунту, у которого отображаемое имя пусто
- **THEN** система сохраняет имя Google как отображаемое имя этого аккаунта

#### Scenario: Явная привязка заполняет пустое имя
- **WHEN** вошедший пользователь без отображаемого имени привязывает Google из профиля, и Google вернул имя
- **THEN** система сохраняет имя Google как отображаемое имя аккаунта

#### Scenario: Заданное имя не перезаписывается
- **WHEN** имя Google отличается от уже заданного отображаемого имени аккаунта
- **THEN** система сохраняет прежнее отображаемое имя и не перезаписывает его

#### Scenario: Повторный вход не меняет имя
- **WHEN** пользователь входит через Google повторно по уже привязанной идентичности, а отображаемое имя задано
- **THEN** отображаемое имя остаётся прежним

#### Scenario: Google не вернул имя
- **WHEN** Google не возвращает имя пользователя или возвращает пустое значение
- **THEN** система завершает вход как обычно и оставляет отображаемое имя пустым

#### Scenario: Слишком длинное имя игнорируется
- **WHEN** имя Google после обрезки пробелов длиннее предела отображаемого имени профиля
- **THEN** система не сохраняет это имя и завершает вход, оставляя отображаемое имя пустым
