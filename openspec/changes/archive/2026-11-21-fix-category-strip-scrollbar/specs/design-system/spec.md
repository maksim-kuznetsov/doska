# Spec Delta

## MODIFIED Requirements

### Requirement: Полоса категорий в шапке

Система SHALL предоставлять горизонтальную полосу разделов под основной строкой шапки на настольной ширине; каждый раздел SHALL быть ссылкой на ленту объявлений, отфильтрованную по этому разделу. При нехватке ширины полоса SHALL прокручиваться по горизонтали без переноса на новую строку, MUST NOT показывать системную полосу прокрутки и SHALL обозначать градиентным затуханием край, у которого остались непросмотренные разделы.

#### Scenario: Переход по разделу

- **WHEN** пользователь выбирает раздел в полосе шапки
- **THEN** открывается лента объявлений, отфильтрованная по выбранному разделу

#### Scenario: Горизонтальная прокрутка полосы

- **WHEN** разделов больше, чем помещается по ширине
- **THEN** полоса прокручивается по горизонтали и не переносится на новую строку, а системная полоса прокрутки не отображается

#### Scenario: Индикатор скрытых разделов

- **WHEN** разделы не помещаются по ширине и у края полосы остались непросмотренные разделы
- **THEN** у этого края видно градиентное затухание содержимого, которое исчезает, когда полоса прокручена до этого края

#### Scenario: Полоса без переполнения

- **WHEN** все разделы помещаются по ширине
- **THEN** градиентное затухание не отображается ни у одного края полосы
