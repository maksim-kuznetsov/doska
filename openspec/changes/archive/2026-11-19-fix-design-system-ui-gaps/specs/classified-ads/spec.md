# Spec Delta

## ADDED Requirements

### Requirement: Публичный просмотр объявления
Система SHALL отдавать активное объявление по публичному адресу без входа в систему и MUST NOT раскрывать по этому адресу объявления в статусах «на проверке», «отклонено», «скрыто», «продано» и «архив».

#### Scenario: Просмотр активного объявления
- **WHEN** посетитель открывает адрес активного объявления
- **THEN** он видит заголовок, цену, описание, контакты, раздел, город, дату и галерею всех фотографий объявления

#### Scenario: Неактивное объявление
- **WHEN** посетитель открывает адрес объявления, которое не находится в статусе «активно»
- **THEN** система не показывает объявление и сообщает, что оно недоступно

#### Scenario: Переход из ленты
- **WHEN** посетитель нажимает на карточку объявления в ленте
- **THEN** открывается публичная страница этого объявления
