# Proposal

## Why

Доменные сущности уже содержат методы с правилами (`Ad.Approve`, `User.Block`, `Category.SetParent` и другие), но все свойства объявлены с открытыми сеттерами, поэтому вызывающий код обходит эти правила: `ad.Status = AdStatus.Active` даёт активное объявление без `PublishedAt`, `user.Role = …` меняет роль без проверок, `new Category { ParentId = … }` нарушает правило двух уровней. Инкапсуляция задумана, но не enforced. Закрываем сеттеры, чтобы правила нельзя было обойти.

## What Changes

- **BREAKING (внутренний API кода):** свойства сущностей `Doska.Domain` получают `private set`; состояние меняется только доменными методами.
- Создание сущностей — только через параметризованные конструкторы (для EF Core — приватный конструктор без параметров); логика статуса по доверию автора переносится в конструктор `Ad`.
- **Время владеет домен:** конструкторы и мутирующие методы принимают `now` и сами проставляют `CreatedAt`/`UpdatedAt`; `AppDbContext` перестаёт штамповать отметки.
- Новые доменные методы для операций, которые сейчас меняют поля напрямую: `User.ChangeRole/SetPassword/ConfirmEmail`, `UserToken.MarkUsed`, `Ad.UpdateDetails/MarkReminderSent`; `now` добавляется в существующие методы без него.
- Сидеры и тесты переводятся на конструкторы и доменные методы (общий тестовый билдер).
- В `platform` добавляется требование об инкапсуляции доменных сущностей и владении временем.

### Modified Capabilities
- `platform`: новое требование «Инкапсуляция доменных сущностей и владение временем» — состояние меняется только доменными методами, создание только через конструкторы, отметки времени проставляет домен.

## Вне рамок

- Схема БД и миграции не меняются: типы и колонки те же, отметки времени остаются в модели.
- Контракты Web API не меняются: тела запросов и ответов уже не переиспользуют сущности.
- Бизнес-правила и их тексты не меняются — меняется только способ доступа к состоянию.
- Оптимистичная блокировка и страховки от «забыл обновить `UpdatedAt`» не добавляются.

## Impact

- `Doska.Domain`: `Entity`, `Ad`, `User`, `UserToken`, `City`, `Category`, `AdPhoto`, `AdComplaint`.
- `Doska.Application`: `AdService`, `AuthService`, `UserService`, `CityService`, `CategoryService`, `ModerationService`, `ComplaintService`, `TrustService`.
- `Doska.Infrastructure`: `AppDbContext` (убираются `TimeProvider`, `ApplyTimestamps`, override `SaveChanges`), `AppDbContextFactory`, сидеры.
- `Doska.Tests`: доменные тесты, API-тесты и `SaveChangesTests` — перевод на конструкторы и билдеры.
