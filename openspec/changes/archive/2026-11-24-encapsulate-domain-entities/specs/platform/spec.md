# Spec Delta

## ADDED Requirements

### Requirement: Инкапсуляция состояния доменных сущностей

Сущности `Doska.Domain` SHALL изменять своё состояние только через методы, выражающие доменное правило. Состояние MUST NOT быть изменяемым извне сущности напрямую: свойства состояния не предоставляют публичного доступа на запись.

#### Scenario: Прямое изменение состояния недоступно

- **WHEN** вызывающий код пытается перевести объявление в статус «активно» присваиванием свойства
- **THEN** такой способ недоступен, а изменение выполняется доменным методом, проверяющим допустимость перехода

#### Scenario: Доменный метод проверяет переход

- **WHEN** доменный метод вызывается в состоянии, для которого переход недопустим
- **THEN** метод отклоняет изменение, состояние сущности остаётся прежним

#### Scenario: Согласованные поля меняются вместе

- **WHEN** доменный метод выполняет допустимый переход
- **THEN** он изменяет состояние вместе со всеми связанными полями, не оставляя их в противоречии

### Requirement: Создание доменных сущностей

Новые сущности `Doska.Domain` SHALL создаваться через конструктор, принимающий обязательные данные. Создание MUST NOT требовать последующего присваивания состояния снаружи.

#### Scenario: Создание новой сущности

- **WHEN** сценарий использования создаёт сущность
- **THEN** обязательные данные передаются в конструктор, а состояние новой сущности соответствует правилам домена

#### Scenario: Материализация из базы данных

- **WHEN** сущность восстанавливается из базы данных
- **THEN** она материализуется без публичного доступа на запись к состоянию

### Requirement: Владение отметками времени

Отметки создания и изменения (`CreatedAt`, `UpdatedAt`) SHALL проставляться доменом: конструктор задаёт обе при создании, доменный метод обновляет `UpdatedAt` при изменении. Слой доступа к данным MUST NOT проставлять эти отметки при сохранении.

#### Scenario: Создание фиксирует время

- **WHEN** сущность создаётся
- **THEN** `CreatedAt` и `UpdatedAt` равны моменту, переданному в конструктор

#### Scenario: Изменение обновляет отметку

- **WHEN** доменный метод изменяет состояние сущности
- **THEN** `UpdatedAt` становится переданным моментом, а `CreatedAt` не меняется

#### Scenario: Сохранение без изменения не двигает время

- **WHEN** изменения сохраняются в базу без вызова доменного метода
- **THEN** `UpdatedAt` остаётся прежним, потому что отметки проставляет домен, а не сохранение
