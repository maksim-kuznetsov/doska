# Proposal

## Why

Список пользователей на `admin/users` выводит всех учётных записей карточками и отдаёт их одним запросом без ограничения. С ростом числа аккаунтов страница становится длинной и трудной для беглого просмотра, а ответ — неограниченным по размеру. Таблица со столбцами читается быстрее, а постраничная выдача ограничивает объём данных на запрос.

## What Changes

- **Список пользователей становится таблицей**: столбцы email, имя, роль, доверие, подтверждение email, статус и контакты; в последнем столбце — ссылка «Редактировать».
- **Постраничная выдача на сервере**: `GET /api/admin/users` принимает `page` и `pageSize` и возвращает страницу (`PagedResult`) с общим количеством; интерфейс листает страницы уже существующим компонентом `Pagination`.
- **Оформление таблицы данных в дизайн-системе**: стили таблицы с заголовком, строками и горизонтальной прокруткой на узкой ширине; пример на странице-гайде.
- Страница правки пользователя (`admin/users/:id`) не меняется.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `user-accounts`: требование «Список пользователей для администратора» дополняется табличным видом свойств и постраничной выдачей.
- `design-system`: добавляется оформление таблицы данных и его пример на странице-гайде.

## Impact

- Бэкенд: `Doska.Application/Accounts/UserService` (`GetListAsync` возвращает `PagedResult<AdminUserView>`), `Doska.Api/Controllers/AdminUsersController` (query-параметры `page`/`pageSize`, ответ `PagedResultResponse<AdminUserResponse>`), тесты `UserAccountApiTests`.
- Интерфейс: `frontend/src/views/AdminUsersView.vue` (таблица + `Pagination`), `frontend/src/api/client.ts` (`adminUsers.list` возвращает `PagedResult<AdminUserView>`), `frontend/src/assets/css/components.css` (стили таблицы), `frontend/src/views/DesignSystemGuide.vue`, тесты интерфейса.
- Схема БД не меняется.
- Формат ответа `GET /api/admin/users` меняется (массив → страница) — **BREAKING** для этого эндпоинта; других потребителей, кроме страницы `admin/users`, у него нет.

## Вне рамок

- Поиск и фильтрация пользователей, сортировка по столбцам.
- Выбор размера страницы пользователем (фиксированный размер по умолчанию).
- Виртуализация длинных списков.
- Изменение страницы правки пользователя.
