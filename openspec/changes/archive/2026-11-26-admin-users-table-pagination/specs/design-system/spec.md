# Spec Delta

## ADDED Requirements

### Requirement: Таблица данных

Система SHALL предоставлять оформление таблицы данных: заголовок столбцов, строки с разделителями, выравнивание ячеек и горизонтальную прокрутку на узкой ширине, чтобы страницы с табличными данными собирались в оформлении системы.

#### Scenario: Заголовок и строки

- **WHEN** страница показывает таблицу данных
- **THEN** заголовок столбцов и строки оформлены в едином стиле системы

#### Scenario: Таблица на узкой ширине

- **WHEN** таблица не помещается в ширину экрана
- **THEN** она прокручивается по горизонтали, не ломая раскладку страницы

## MODIFIED Requirements

### Requirement: Страница-гайд дизайн-системы
Система SHALL предоставлять страницу-гайд (`frontend/src/views/DesignSystemGuide.vue`) на маршруте `/design-system`, показывающую токены и все компоненты с примерами разметки, доступную только в окружении `Development`.

#### Scenario: Просмотр гайда
- **WHEN** разработчик открывает адрес гайда в окружении `Development`
- **THEN** он видит токены и примеры всех компонентов

#### Scenario: Примеры новых компонентов
- **WHEN** разработчик открывает гайд после перевода представлений на компоненты дизайн-системы
- **THEN** на странице есть примеры фильтров с диапазоном цены и строкой результатов, галереи, строк списка, карточек модерации, подсказок к паролю, бургер-меню, ссылки-действия с иконкой, флажка, таблицы данных, а также секций формы, сетки коротких полей, зоны загрузки фотографий и счётчика символов

#### Scenario: Гайд в production
- **WHEN** окружение — `Production`
- **THEN** страница-гайд недоступна
