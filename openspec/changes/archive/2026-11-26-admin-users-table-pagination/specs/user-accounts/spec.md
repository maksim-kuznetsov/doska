# Spec Delta

## MODIFIED Requirements

### Requirement: Список пользователей для администратора

Система SHALL показывать администратору список учётных записей таблицей со столбцами: email, отображаемое имя, роль, доверие, подтверждение email, блокировка и контакты. Каждая строка SHALL содержать ссылку на страницу редактирования этой записи. Список SHALL выдаваться постранично с общим количеством. Доступ SHALL требовать роль `Admin`.

#### Scenario: Просмотр списка

- **WHEN** администратор открывает раздел пользователей
- **THEN** он видит таблицу учётных записей со столбцами свойств и ссылкой на редактирование в каждой строке

#### Scenario: Список не даёт редактировать на месте

- **WHEN** администратор просматривает список
- **THEN** изменение свойств доступно только по ссылке на страницу записи, а не прямо в таблице

#### Scenario: Постраничная выдача

- **WHEN** учётных записей больше, чем помещается на страницу
- **THEN** список показывает одну страницу и общее число страниц, а переход на другую страницу запрашивает её у сервера

#### Scenario: Размер страницы ограничен

- **WHEN** клиент запрашивает страницу с размером больше допустимого
- **THEN** сервер ограничивает размер страницы допустимым максимумом

#### Scenario: Пустой список

- **WHEN** учётных записей нет
- **THEN** страница показывает, что пользователей нет, вместо пустой таблицы

#### Scenario: Доступ только администратору

- **WHEN** список запрашивает неавторизованный пользователь или не администратор
- **THEN** сервер отвечает отказом и не раскрывает данные учётных записей
