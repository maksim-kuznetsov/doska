# Spec Delta

## Purpose

Определяет, как статические файлы интерфейса (CSS и JS) получают версию в адресе и как кешируются статика и HTML, чтобы после обновления сайта браузер не использовал устаревшие файлы.

## ADDED Requirements

### Requirement: Версия статики в адресе файла

Ссылки на CSS и JS в HTML-оболочке SPA SHALL содержать версию, вычисленную из хеша содержимого файла при сборке Vite. При изменении файла адрес в HTML MUST измениться, поэтому ранее закешированная копия не будет использована.

#### Scenario: Первый деплой версии

- **WHEN** интерфейс собран и HTML-оболочка отдана пользователю
- **THEN** в разметке страницы адреса CSS и JS содержат версию файла

#### Scenario: Файл изменился

- **WHEN** содержимое CSS или JS изменено и сборка Vite выполнена повторно
- **THEN** HTML-оболочка ссылается на новый адрес, а старый адрес остаётся доступным

#### Scenario: Файл не изменился

- **WHEN** сборка Vite выполнена повторно без изменения файлов
- **THEN** адреса CSS и JS в HTML остаются прежними

### Requirement: HTML отдаётся без кеширования

Ответы с HTML SHALL сопровождаться заголовком `Cache-Control: no-cache`, чтобы браузер ревалидировал страницу и получал ссылки на актуальные версии статики.

#### Scenario: Запрос HTML-страницы

- **WHEN** браузер запрашивает HTML-оболочку SPA у nginx
- **THEN** ответ содержит `Cache-Control: no-cache`

#### Scenario: Повторный визит после деплоя

- **WHEN** пользователь повторно открывает страницу после обновления сайта
- **THEN** браузер ревалидирует HTML и получает ссылки на новые версии CSS и JS

### Requirement: Кеширование версионированной статики

Статические файлы SHALL отдаваться с разрешённым браузерным кешем, а разные версии одного файла MUST иметь разные адреса, чтобы кеш одной версии не влиял на другую.

#### Scenario: Повторный запрос статики

- **WHEN** браузер в пределах срока кеша запрашивает CSS или JS по адресу с версией
- **THEN** файл берётся из кеша без обращения к серверу

#### Scenario: Смена версии

- **WHEN** файл изменился и HTML-оболочка ссылается на новый адрес с версией
- **THEN** браузер загружает новый файл, не используя старую кешированную копию

### Requirement: Статика в режиме разработки без сборки

В окружении Development и без предварительной сборки ассетов страницы SHALL открываться и ссылаться на доступные адреса CSS и JS, чтобы локальная разработка и тесты не требовали отдельного шага сборки.

#### Scenario: Локальный запуск без предварительной сборки

- **WHEN** интерфейс запущен dev-сервером Vite без сборки
- **THEN** страницы отображаются без ошибок подключения ассетов

#### Scenario: Тесты без собранной статики

- **WHEN** запускаются тесты без предварительной сборки ассетов
- **THEN** представления отображаются без ошибок версионирования
